## A few pieces built the hard way, on purpose

- 🎨 **A canvas built from scratch** — depth-layered particle backgrounds with parallax, no charting or animation library involved.
- ♟️ **A chess engine that never leaves the browser** — a real chess engine compiled to WebAssembly, running inside a Web Worker: full game analysis, zero server cost.
- 🔐 **Auth built for an audience of one** — no login-as-a-service; a minimal, auditable signed-JWT session flow sized exactly to what a single-user system actually needs.
- 🧩 **A design system, not a component library** — every glass panel, glow, and gradient traces back to a handful of shared tokens.
- 🤖 **This README, updating itself** — the "right now" line above, the chart below, and the board below that are all regenerated by scripts I wrote, run on a schedule, committed by a bot. See [how](#how-this-profile-stays-honest).

## How this profile stays honest

Nothing above is hand-typed decoration. Three scheduled GitHub Actions keep it true without me touching it:

| What | Script | Runs |
|---|---|---|
| "Right now" line | [`update_now.mjs`](scripts/update_now.mjs) | every 4 hours, off the public Events API |
| Contribution chessboard | [`generate_chess_heatmap.mjs`](scripts/generate_chess_heatmap.mjs) | daily, off GitHub's own contribution calendar |
| LeetCode rating chart | [`generate_leetcode_chart.mjs`](scripts/generate_leetcode_chart.mjs) | daily, off LeetCode's GraphQL API |

The hero banner ([`generate_hero.py`](scripts/generate_hero.py)) is a static hand-authored SVG — starfield, comet streaks, a rotating gradient ring, and a shimmer sweep, all native SVG animation, no banner-generator service involved.
