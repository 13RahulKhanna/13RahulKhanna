## A few pieces built the hard way, on purpose

- 🎨 **A canvas built from scratch** — depth-layered particle backgrounds with parallax, no charting or animation library involved.
- ♟️ **A chess engine that never leaves the browser** — a real chess engine compiled to WebAssembly, running inside a Web Worker: full game analysis, zero server cost.
- 🔐 **Auth built for an audience of one** — no login-as-a-service; a minimal, auditable signed-JWT session flow sized exactly to what a single-user system actually needs.
- 🧩 **A design system, not a component library** — every glass panel, glow, and gradient traces back to a handful of shared tokens.
